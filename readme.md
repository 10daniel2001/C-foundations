# C foundations

Este repositorio e para estudo de fundamentos da linguagem C, com foco em estruturas de dados, algoritmos e boas práticas de programação, é para uso de estudantes e profissionais que desejam aprimorar seus conhecimentos na linguagem C, e para aqueles que desejam aprender a programar em C do zero.

### Estrutura do repositório
- `algorithms`: Contém implementações de algoritmos clássicos em C, como ordenação, busca, grafos, entre outros.

- `data_structures`: Contém implementações de estruturas de dados em C, como listas, pilhas, filas, árvores, entre outros.

- `memory`: Contém implementações de gerenciamento de memória em C, como alocação dinâmica, desalocação, e técnicas de otimização de memória.

- `notes`: Contém tudo sobre POO, como conceitos, exemplos e boas práticas de programação orientada a objetos em python.

Pointers: Contém exemplos e explicações sobre ponteiros em C, incluindo ponteiros para funções, ponteiros para estruturas, e técnicas avançadas de manipulação de ponteiros.

my_codes contem implementações de códigos próprios em C, incluindo projetos pessoais, desafios de programação, e exemplos de código para estudo.

# Em Inglês

This repository is for studying the fundamentals of the C language, focusing on data structures, algorithms, and good programming practices. It is intended for students and professionals who wish to improve their knowledge of the C language, as well as for those who want to learn to program in C from scratch.

### Repository Structure
- `algorithms`: Contains implementations of classic algorithms in C, such as sorting, searching, graphs, and more.

- `data_structures`: Contains implementations of data structures in C, such as lists, stacks, queues, trees, and more.

- `memory`: Contains implementations of memory management in C, such as dynamic allocation, deallocation, and memory optimization techniques.

- `notes`: Contains everything about OOP, such as concepts, examples, and good programming practices in Python.

- `pointers`: Contains examples and explanations about pointers in C, including function pointers, structure pointers, and advanced pointer manipulation techniques.

- `my_codes`: Contains implementations of personal codes in C, including personal projects, programming challenges, and code examples for study !!
